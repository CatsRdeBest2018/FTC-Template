# New Season Setup Checklist

1. Update the FTC SDK and third-party dependencies.
2. Create and save the Robot Controller hardware configuration.
3. Record every device in `hardware-map.md`.
4. Update `HardwareNames.java` to match the configuration exactly.
5. Add the current robot's subsystem classes.
6. Configure and tune localization and path following.
7. Verify each device with a debug OpMode.
8. Create and test competition TeleOp and autonomous OpModes.
9. Record driver controls in `controls.md`.
